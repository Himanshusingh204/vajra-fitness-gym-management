**VajraFitness (Gym Management SaaS)** | *React, Node.js, TypeScript, PostgreSQL, Prisma, Tailwind CSS*

- Built a multi-tenant platform allowing owners to manage gym branches, memberships, and staff via a React dashboard.
- Wrote custom Express middleware for role-based access control to securely isolate data between admins, trainers, and members.
- Integrated Razorpay for online payments, generated PDF receipts, and set up cron jobs to automate membership expirations.
